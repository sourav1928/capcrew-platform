# About these notes

The files in this folder are build notes inherited from the original extension-cord store this project
was copied from. They describe how the shop and admin panel were built. Some examples may still mention
extension boards, old ports (5173/5174/8000) or the old brand name. For the current setup, use the
top-level `README.md`. `ADMIN_SITE_README.md` has been updated to the caps ports.
